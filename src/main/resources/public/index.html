Images

Wanda draws pictures with FLUX on Cloudflare Workers AI. Cloudflare's free plan includes a daily allowance, and when it runs out you simply get an error (you are never charged).

  1. Create a free account at cloudflare.com.
  2. In the dashboard open AI → Workers AI, choose Use REST API and copy your Account ID.
  3. On the same page click Create a Workers AI API Token and copy the token.
